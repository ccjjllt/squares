## 保留的研究主线

**多样供体 → 迁移 / 接缝交叉 → 分阶段松弛 → 赢家续压 → 双路径验证 → 逐题合并。** CPU 生成离散候选，GPU 按同 n 批量松弛；正式收益只计算最终选中的合法完整 n 组。

| 有效结果 | 来源与贡献（相对公共 v33） |
| --- | --- |
| n=459 | Daily 的 `551→504→459` 两步迁移链，再继续压缩；分数下降约 `9.514981636e-6` |
| n=642 | Penguin 与 Atlas 的 n=591 交叉中间态迁移到 642，再继续压缩；分数下降约 `1.214848869e-5` |

代码入口保留 `prepare_candidates.py`、`run_gpu_pilot.py`，搜索模块保留 `structure.py`、`gpu_relax.py` 和按需调用的 `local_repair.py`。`squares merge` 保留完整题组、原始坐标文本、双路径评分和来源追踪。

新赢家已能自适应续压并导出，但进入下一轮迁移 / 交叉仍需再次运行候选生成脚本。当前没有在线自动生成下一代的完整循环，也没有按接触拓扑组织的供体档案。具体命令见[使用指南](getting-started.md)。

## 已完成实验与停止原因

| 路线 / 实验 | 已观察到的结果 | 当前决定及原因 |
| --- | --- | --- |
| Pilot01 | 96 候选×2轮，CUDA 约79.4秒；零直接赢家 | 清除运行副本，仅留进入后续赢家血缘的近优供体；零即时收益不等于中间态没有价值 |
| Pilot02、Pilot04 | Pilot02 改善642；Pilot04 24候选、30续压批次，约494.6秒，改善459与642 | 保留有效主线、赢家、谱系和小型复现材料，删除重复完整CSV |
| 独立固定角度 LP 续压 | 21次尝试、8次接受，约21.1秒；相对Pilot02累计额外改善约`1.364892361e-7`，随后被Pilot04覆盖 | 停止独立路线，删除专用脚本及产物；收益小且不再贡献最终结果。GPU主线的可选修复模块仍保留 |
| 小核心 / 薄带编辑与有限 refill | 29候选，固定角CPU和Pilot05自由角GPU均无净收益 | 停止当前编辑器，删除实现、候选及运行结果；有限编辑未显示效果，不将其扩大为完整FTMC工程 |
| 有限两列矩形构件组合 | 128 / 512构件，各检查1000题，合计约14.3秒；容量改善为0，没有候选进入官方评分 | 停止当前组合器，删除实现及构件库；它没有独立优化矩形，也不是完整递归DP |
| Pilot05 扩展批次 | 29个core + 12个多切口交叉候选，约244.7秒；零赢家，完整输出与Pilot04相同 | 删除整轮产物和重复CSV；保留仍在有效血缘中的通用交叉算子，不原样重复同一批候选 |
| 大规模局部 LP 修复 | Pilot04 173次约207秒，仅5次通过浮点修复；Pilot05 83次约115秒，无新赢家 | 不作为普遍优化路线；只在主线中按较小穿透量筛选使用。求解失败不证明几何不可行 |
| 专用 GPU 吞吐研究 | n642、600步、三次重复，batch8/32/64约26.17/105.94/130.36条轨迹/秒 | 测量任务已结束，保留结论、删除专用脚本与原始输出；吞吐提升不是分数收益，也不保证跨题通用 |
| 旧 Stretching / Boxed 基线分析 | 原分析定位了大n及106题历史候选，但依据旧基线与2026-10-29纪录 | 删除旧分析脚本、表图、公共旧CSV及重复规划；不把旧约0.06463差距当当前可获收益 |

主要瓶颈是可行性修复：Pilot02 中80条结构轨迹的原始包围盒更小，其中76条修复后失去收益。原始边长或碰撞损失的下降不能替代官方有效分数。

## 当前不实施的方向

- **完整 FTMC / Rust、递归 fault-line DP、矩形独立优化**：本项目尚未完成；实现与维护成本较高，先集中到已有真实赢家的结构路线。已删除仅用于这些调研的 evand 源码摘录及下载 Notebook。
- **fq 圆角压力硬化、Soft-to-Rigid、渐近构造、pinwheel / 全局非线性探索**：没有本地有效收益证据，不继续维护计划或下载材料。若重新启动，应先说明目标题和小规模可验证实验。
- **成熟布局全量 SLP、无结构随机重启、统一延长松弛、复杂多 GPU / FP32 工程**：当前不投入主预算；优先解决候选结构与修复成本。外部负面报告或本轮小样本不构成普遍结论。

这些方向只有在出现新构型、可复用实现或明确的小规模收益证据后才重新评估；不会因为旧计划里列过就自动继续。
