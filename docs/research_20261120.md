## 关键研究发现

1. **过去只用 evand `packer hop`（3.3e-7 score/CPU-h），同 repo（pin==HEAD）的 `fq`/`harden`/`hhop` 从未用。** alexchilton 实测 fq 系 **0.004 score/CPU-h（30-50×）**。`fq` 平滑 ALM 无 max-over-axes 折点；`harden` Nakajima 动量软→刚（~17k 步，方块互相滑过）；`hhop` 硬事件链沿接触链传播到对侧墙（对口 651 题 6 块协同）。
2. **重叠起点必须 `--round-r0 0.15 --round-compress`，否则塌回 k+1 网格**（evand schedules.py 警告）——解释旧 GPU 可微 SAT 滑行 396 题 0 胜。
3. **alexchilton gadget quench + fault DP 代码 CC0 公开**（starter kit v91：fault_dp.py/quench_gadgets.py/skeleton.py）。但**我们 bank 已含其输出，照抄零胜**（本轮实测：19 gadget 的 f 改善，0 认证逐题胜，净增益 1.86e-13）。
4. **GeiserX 代码 Apache-2.0 公开**（k123_join/k123_tartan/k123_step57，须署名 Sergio Fernández Rubio）。band 族跨题 join（接缝两侧链宽相等、par 取整共格、接缝直立块重铺、斜带不动）；arm 族 family_step/modules。
5. **Sparrow 否决**（论文 §10 明说产不出单位正方形精确接触解，只条带装填）。
6. **730 家族（730/785/842/901/962）= 289=17² 个 45° 实心核 + 轴向圈**，frac 恒 0.520815；GA rank.py 排除 ≥5 个 45° 方块的题。突破需 tartan 滑移（17 宽 phi=2.385°），是 GeiserX 三轮「still not built」的开放项（价值 ~0.005，11 个 n）。

## tartan MIP 技术细节（负结果，供后续）

模型 `tartan_mip.py`：每行×滑移台阶、每列×错移台阶各 one-hot 0/1 变量，`step=√2·tan(psi)`，`t=45°+psi`（held 261 t0=48.118°=45°+3.118°）。斜块中心对 (O,S,R) 线性、直立格对 L 线性；近绑定 tilted-upright 对用 4 轴×2 向 big-M 析取，解后精确四轴 min_gap 验证、违例对提升为析取再解（懒精确）；scipy.optimize.milp(HiGHS) 最小化 L。

**已修 bug**：`cost=np.zeros(self.nvar)` 原在循环外只建一次，`_promote` 增加变量后 integrality 变长导致 `integrality must be broadcastable to c.shape`；改为每轮重建 cost。

**未解问题**：261 对照 MIP 收敛到 L=16.695874（>held 16.678780）且 verified=False（仍有重叠，rnd 0 gap −1.12/wall 5.94）。懒细化 `promote=[key for key in viol_pairs if key in self._fixed]` 只提升 fixed 轴违例对，析取对重叠不解决；big-M=2·L_hi+2 过松允许数值重叠。需重审析取可行性公式（紧 big-M / 可行性泵 / 违例析取对精确分离约束）。对照门未过即停，未攻目标题。

**第二轮修复（promote 所有未析取违例对）**：`promote=[key for key in viol_pairs if not self._disjoin.get(key)]`。rnd 1 析取 67→181、nvar 829→1741，但解仍 L=16.695874/gap −1.10/wall 5.96（几乎不变）。**诊断升级**：加析取不改善 → 根因非缺失析取，而是 MIP 线性中心表达式 `_C_expr` 与 `H.layout(t,O,S,R,L)` 实际几何不一致（墙约束约束的是错误几何，wall 违例 5.96 远超数值容差）。需逐行比对 `_C_expr`/`H.centres`/`H.layout` 的 slip S_j/R_i 符号、O 偏移、L 缩放一致性。此为开放项根本难度，且 17×17 即便修好大概率不优于 held（GeiserX 连续 outline 负结果），期望收益低，本轮止于此诊断。
